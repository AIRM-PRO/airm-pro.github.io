# airm-pro.github.io

WebXR games for Meta Quest, played in the Quest Browser. Served by GitHub Pages at **https://airm-pro.github.io**.

| Game | URL | Folder |
|---|---|---|
| Orbital Brawl (VR brawler) | https://airm-pro.github.io/bravr | `bravr/` |
| Skrzydła (winged flight over a procedural city) | https://airm-pro.github.io/skrzydla | `skrzydla/` |
| NinjaLingo (cut the food the voice shouts in Spanish) | https://airm-pro.github.io/ninjalingo | `ninjalingo/` |

Each game is a single `index.html` with no build step. Push to `main` and Pages deploys in about a minute. Developer notes for each game are in its folder's `CLAUDE.md`.

Moved here from `jknowak/jknowak.github.io` (jknowak.pl/bravr, jknowak.pl/skrzydla) in November 2026 with git history.
